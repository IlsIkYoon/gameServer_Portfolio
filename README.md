안녕하세요 게임 서버 프로그래머 지원자 윤일식입니다.
이 리포지토리는 포트폴리오 제출을 위해 기존 리포지토리에서 코드를 복사 붙여넣기 해서 커밋 내역이 없습니다.

리포지토리 내부에 솔루션 하나에 프로젝트 여러개가 들어가있는 구성이고 빌드 종속성을 이용해 네트워크를 위한 정적 라이브러리 파일을 먼저 빌드한 뒤 각 프로젝트 코드들이 빌드되는 방식으로 구성되어 있습니다.
이는 개발 과정에서 네트워크 라이브러리 수정이 계속 이뤄져왔기에 개발 편의성을 위한 구성이었습니다.

네트워크 라이브러리는 iocp모델을 사용해 동기화 객체를 사용하지 않는 방식으로 구현했으며 동시성 문제는 인터락으로 모두 해결했습니다.
성능 향상을 위한 목표보다는 동시성 문제를 경험하고 해결해나가는 과정에 초점을 두었습니다.

구성은 싱글스레드 채팅 서버, 멀티스레드 채팅 서버, 로그인 서버, 채팅서버 검증용 더미 클라이언트 , 모니터링 서버, 네트워크 라이브러리로 구성이 되어 있습니다.
로그인 서버를 거쳐 채팅 서버로 로그인하는 과정에서 토큰 저장소로 Redis가 사용되었으며 모니터링 서버에서 모니터링 log를 저장하는 과정에서 mysql을 사용했습니다.
